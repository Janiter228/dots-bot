# dots-bot

Бот для игры «Точки» (проектный практикум ИРИТ-РТФ, турнирный эмулятор).
Все работаем в своих ветках!!! 

## Быстрый старт

```bash
npm start          # сервер на порту 4003 (нужен Node.js 20+)
npm test           # автотесты
```

Для развёртывания используйте Docker Compose: подготовьте `.env` по [инструкции запуска](docs/RUNBOOK.md), затем выполните `docker compose up -d --build`.

Для проверки в «Песочнице» на сайте арены укажите `http://localhost:4003`.
Для «Проверки API» в кабинете нужен публичный https-адрес без редиректов.

## Играть в браузере

1. Откройте `web/index.html` двойным щелчком в современном браузере. Локальная игра на двоих работает без сервера, библиотек и сборки.
2. Для игры с ботом выполните `npm start`, переключитесь в режим **«Против HTTP-бота»**, укажите адрес (по умолчанию `http://localhost:4003`) и свой цвет. Выберите размер поля и нажмите **«Новая партия»**.
3. Красные начинают. Ставьте точки щелчком по свободному пересечению или стрелками и Enter. Кнопка **«Вписать»** показывает всё поле, ползунок меняет масштаб.
4. Нажмите **«Показать захват»**, чтобы открыть учебный пример: четыре красные точки замыкают контур вокруг синей. Включите **«Карту окружений»**, чтобы увидеть замкнутые области, в том числе пустые.
5. В **«Разборе партии»** можно перемотать ходы ползунком, перейти по журналу или запустить автовоспроизведение. Просмотр не влияет на текущую позицию: клики по полю заблокированы, а кнопка **«К игре»** возвращает управление.
6. Кнопка **«Отменить ход»** возвращает позицию к предыдущему ходу; в игре с ботом ход бота откатывается вместе с вашим.

Страница отправляет `POST {адрес}/v1/move` в формате арены: `gameId`, `moveNo`, `you`, `field`, `points`, `dead`, `score`, `last`, `moveTimeoutMs`, `timeLeftMs`. Ответ `{x, y}` проверяется на границы и занятость, включая мёртвые точки.

### Журнал и красивая консоль

При `npm start` терминал показывает цветной стартовый блок: версию алгоритма, адрес, маршруты API, статус авторизации и подсказку запуска игры. Цвет включается в интерактивном терминале; при перенаправлении в файл вывод остаётся обычным текстом. Переменная `NO_COLOR` отключает цвет. Значение токена не выводится.

Справа на странице — последние 100 событий: ходы, время ответа и ошибки. В **F12 → Console** события сгруппированы и имеют цветные заголовки. Раскройте группу HTTP-запроса, чтобы увидеть отправленную позицию и ответ.

Проверить сервер отдельно в PowerShell:

```powershell
Invoke-RestMethod http://localhost:4003/v1/health | Format-List
```

### Если бот недоступен

- Проверьте, что `npm start` запущен, а адрес и порт совпадают с настройками страницы. Если браузер запросит доступ к локальной сети, разрешите его.
- HTTP-ошибка, недопустимый ответ или таймаут 5 секунд означают пропуск бота. После своего хода нажмите **«Продолжить: ход бота»** для повторного запроса. После 11 последовательных пропусков — техническое поражение бота.
- **«Новая партия»** отменяет текущий запрос; поздний ответ не применяется к новой позиции.
- Страница не передаёт токен авторизации. Для локальной игры используйте сервер без обязательного `BOT_TOKEN`.
- Если браузер блокирует запросы из локального файла и установлен Python, выполните `python -m http.server 8080 --bind 127.0.0.1` в корне проекта и откройте `http://127.0.0.1:8080/web/`. Сервер бота остаётся работать на 4003.

### Правила и конец партии

Захваты считаются в странице по областям четырёхсвязности. Стены — только живые точки цвета. Мёртвые точки сохраняют цвет и занимают пересечение, пустая территория очков не даёт. Окружения пересчитываются до стабильности с возможным оживлением. Партия завершается при заполнении поля или исчерпании общего бюджета ответов 15 минут. Победитель определяется по числу захваченных точек; время обдумывания человека не списывается.

**Проверка правил:** реализация ещё не сверена с эталонными правилами арены. Сначала обрабатывается цвет сделавшего ход, затем другой цвет. При цикле или превышении предела пересчёта партия останавливается с диагностикой. Совпадение счёта с песочницей для вложенных окружений не подтверждено.

## Структура проекта

```text
dots-bot/
├── README.md                    этот файл
├── SKILL.md                     контекст и правила для ИИ-ассистента
├── package.json                 команды npm start и npm test
├── .env.example                 пример настроек (PORT, BOT_TOKEN)
├── Dockerfile                   сборка образа
├── docker-compose.yml           запуск одной командой
├── .github/
│   ├── workflows/ci.yml         тесты на каждый push и pull request
│   └── CODEOWNERS               кто смотрит какую папку
├── bot/index.js                 алгоритм: chooseMove(request) -> {x, y}
├── server/index.js              HTTP API для арены
├── web/index.html               интерфейс для игры человека против бота
├── tests/
│   ├── api.test.mjs             тесты API
│   ├── rules.test.mjs           тесты правил игры
│   ├── regression.test.mjs      тесты тактики: захваты, блоки, вилки
│   └── match.mjs                бот против бота
└── docs/
    ├── STRATEGY_SHORT.md        краткое описание и история стратегии
    ├── STRATEGY_LONG.md         подробный разбор алгоритма
    └── RUNBOOK.md               запуск в Docker и диагностика
```
