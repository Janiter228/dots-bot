\# 🚨 RUNBOOK: Действия при аварии



\## Симптомы

Арена пишет о пропусках ходов или техническом поражении.



\## Шаг 1: Проверка здоровья

Открой в браузере: `https://твой-адрес/v1/health`

Должен вернуться `{"status":"ok"}` за < 1 секунды.



\## Шаг 2: Просмотр логов

docker compose logs --tail=100 -f



Ищи ошибки 5xx или таймауты (лимит на ход = 5000 мс).



\## Шаг 3: Перезапуск

docker compose restart



\## Шаг 4: Откат версии

git checkout предыдущий-рабочий-коммит

docker compose up -d --build
