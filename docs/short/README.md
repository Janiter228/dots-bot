# Как играет бот 0.5.0

На пустом поле бот ставит точку в центр. В середине игры он сначала проверяет, какую группу можно захватить или потерять за один ответ. При угрозе крупной потери он пробует занять клетку замыкания и сравнивает этот ход с контрзахватом. На 245-м ходу против Hardware потеря 67 точек была уже неизбежна.

На конечном поле бот имитирует свои ходы и ответы противника. Захваченные точки определяют счёт. На полях площадью 100–2500 клеток бот оценивает, какие группы окажутся внутри стен, если заполнить прямые разрывы в одну клетку. Когда остаётся до семи свободных клеток на поле площадью до 400, бот пробует просчитать партию до конца. На безграничном поле работает отдельный разреженный поиск.

По умолчанию играет самостоятельный алгоритм. Для подключения обученных советников задайте в окружении `DOTS_AI_MODE=hybrid`. Значения `strategist` и `critic` включают по одному советнику. Они влияют на порядок проверки ходов. Ход выбирает поиск, а сервер повторно проверяет клетку.

`MAX_RESPONSE_TIME_MS=2000` задаёт общий бюджет HTTP-запроса. Лимит арены и остаток часов могут сократить его. На больших полях бот также учитывает, сколько ходов ещё предстоит сыграть. Лимит можно изменить и перезапустить сервер.
