# Стратегия Dots Bot v0.3

Историческая версия. Актуальная стратегия, результаты и ограничения — в [STRATEGY.md](STRATEGY.md).

## Что изменилось

Версия 0.3 использует ограниченный minimax глубины 2 полухода: бот оценивает свой ход, затем перебирает ограниченный набор сильнейших ответов соперника и выбирает ход с наилучшей оценкой худшего ответа.

### 1. Генерация кандидатов

- В дебюте рассматривается радиус 2 вокруг живых точек; в более заполненной позиции — радиус 1.
- В начале партии дополнительно рассматриваются клетки около центра.
- Мёртвые точки считаются занятыми и не создают фронтир, потому что не участвуют в контурах.
- Кандидаты сортируются по локальной позиционной оценке; для тактической проверки берётся небольшой список лучших клеток.

### 2. Моделирование захвата

- Живые точки соединяются по 8 направлениям.
- Области проверяются flood fill по 4 направлениям.
- Мёртвые точки не являются стенами.
- Точка в области, уже окружённой соперником, сразу отмечается мёртвой.
- После хода симуляция ищет точки соперника в замкнутых областях и переводит их в мёртвое состояние.

### 3. Оценка позиции

Используются:

- разница захваченных точек;
- число живых точек;
- связность групп по 8 направлениям;
- штраф за изолированные одиночные точки;
- количество пустых клеток фронтира, доступных рядом с группами.

Эта оценка является внутренней эвристикой поиска, а не формулой официального счёта арены.

### 4. Ограничения времени

- Максимальный внутренний бюджет — 1850 мс.
- Фактический бюджет дополнительно ограничивается долей `moveTimeoutMs` из запроса.
- В поиске используются ограниченные списки: до 28 наших ходов и до 10 ответов соперника на каждый ход.
- Если время почти закончилось, бот возвращает лучший уже найденный ход; сервер также сохраняет запасной выбор свободной клетки.

### 5. Известное ограничение

В репозитории отсутствует эталонный движок арены (`engine/adapter.js` пустой). Поэтому поисковая симуляция версии 0.3 моделирует непосредственный захват после каждого хода, но не полную цепочку вложенных окружений с оживлением ранее захваченных точек. Текущая позиция читается из `points` и `dead`, присланных ареной. До подключения эталонного движка стратегическая оценка таких редких сложных ситуаций остаётся приближённой.

## Как проверять

```bash
npm test
npm run bench
```

Для реального сравнения силы стратегии используйте одинаковые пары партий со сменой первого хода против случайного, жадного и эталонного ботов арены. Сравнивайте процент побед, среднюю разницу счёта и время ответа. Прохождение unit-тестов само по себе не доказывает турнирную силу.
