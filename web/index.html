Журнал партии

    Подробности HTTP-запросов — в консоли браузера (F12 → Console).

    Как играть и как считаются захваты

    Запустите сервер командой npm start, укажите его адрес и нажмите «Новая партия». Кликайте по свободным пересечениям в свой ход. Масштаб меняется ползунком, большое поле прокручивается. Время человека на обдумывание не расходует таймер.

    Живые точки цвета служат стенами; остальные клетки связаны по четырём направлениям. Область, не касающаяся края, окружена. Вражеские точки внутри становятся мёртвыми и занимают клетки. Пустая область очков не даёт. После хода состояние пересчитывается до стабилизации с возможным оживлением точек.

    Это локальная реализация по описанию спецификации, ещё не сверенная с движком арены. Для неоднозначных циклов пересчёта игра останавливается с диагностикой. Нельзя утверждать совпадение счёта с ареной без такой сверки.

    Ошибка запроса, ответ вне поля или таймаут 5 секунд — пропуск бота. После 11 пропусков подряд бот проигрывает технически. Для повторной попытки нажмите «Продолжить: ход бота» после своего хода. При заполнении поля или исчерпании общего времени победитель определяется по счёту.
