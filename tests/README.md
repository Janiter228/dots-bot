# Проверки для разработки

`npm test` запускает проверки алгоритма, регрессий и HTTP API. API-тестам нужен доступ к локальным TCP-портам. Ошибка запуска сервера теперь завершает тесты с причиной вместо зависания.

`node --test tests/bot.test.mjs tests/regression.test.mjs` не требует сети.

Для проверки правил положите оригинальный `dots.mjs` от организаторов вне тестов и задайте абсолютный путь. Тесты правил явно пропускаются при отсутствии файла.

```bash
DOTS_ENGINE=/absolute/path/dots.mjs node --test tests/rules.test.mjs
DOTS_ENGINE=/absolute/path/dots.mjs node tests/match.mjs > matches.json
DOTS_ENGINE=/absolute/path/dots.mjs DOTS_SIZES=10,20,30 DOTS_SEEDS=1,17,42 node tests/match.mjs > matches.json
```

Матчи играются против воспроизводимого случайного соперника, каждым цветом, до заполнения поля. Набор по умолчанию содержит 12 партий. JSON содержит параметры, счёт, завершённость, ошибки, среднее/p95/максимальное время и последовательность ходов для воспроизведения. Ошибка или незавершённость дают ненулевой код выхода. Проигрыш сам по себе не является ошибкой протокола. Для сравнения стратегий используйте счёт и одинаковые параметры.

Seed фиксирует генератор соперника. Сам бот ограничивает поиск реальным временем, поэтому на разных машинах ходы могут различаться. Сохранённая последовательность позволяет разбирать конкретную партию.

Полный матч 100×100 может занять значительное время. Для быстрого цикла разработки используйте 10×10, затем увеличивайте размер.
